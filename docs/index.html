Features

A complete screen analysis solution with cutting-edge AI

📱

Screen Capture

Real-time screen capture with floating overlay controls. Analyze anything displayed on your Android device.

📷

Camera Capture

Live camera preview at 30 FPS with tap-to-capture analysis. Toggle between front and back cameras.

🧠

VLM Analysis

Ask questions about what's on your screen using 9 tested vision language models (Qwen, LFM, SmolVLM, Granite). Other llama.cpp models may also work.

🎙️

Offline TTS

Text-to-speech output using sherpa-onnx. Results are spoken aloud without needing internet.

⚡

GPU Acceleration

Adreno GPU support via OpenCL for on-device inference on phones without a supported NPU.

🔧

NPU Support

Runs the language model and vision encoder on Hexagon HTP at about 41 tokens/sec. Leverages your phone's dedicated AI processor.

Backend Modes

Choose how you want to run inference

☁️ Remote Mode

Connect to a remote llama.cpp server for powerful cloud processing.

  • Use large models (70B+, 122B+)
  • Best quality with powerful models
  • Simple setup
  • Requires network connection
llama-server -hf unsloth/Qwen3.5-122B-A10B-GGUF:UD-Q4_K_XL -c 262144

📱 Local Mode

Run inference directly on your device with no internet needed.

  • Works completely offline
  • No network latency
  • Privacy - data stays on device
  • CPU / GPU / NPU acceleration
Backend: GPUOpenCL (Adreno) | HTP0 (Hexagon, 1 session recommended)

Quick Start

Get up and running in minutes

1️⃣ Download and install app

Get the latest release and install on your Android device.

Download v2.1

2️⃣ Choose Mode

Select REMOTE (cloud with powerful models) or LOCAL (on-device, offline mode).

3️⃣ LOCAL Inference

If you want to run local inference (offline, on-device):

Download and push a model to your device:

Tested Models (9, with download links)

Then select model path in Local Settings, update parameters, backend and press Save. Then press Start Local and wait until you see "Backend" in green. Then press Start Analyzer.

4️⃣ Remote Inference

If you want remote inference (cloud, powerful models):

Set your llama.cpp server URL in Remote Settings. Press Save and then press Start Analyzer.

5️⃣ Start Analyzing

Tap capture button to analyze. Results spoken aloud via offline TTS.
